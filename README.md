## ✨ Features & Architecture

- **Bespoke Obsidian Dark Aesthetic**: Custom design system featuring deep surface layers, warm gold accents (`#c9a84c`), rose-gold subtle gradients, and glassmorphic depth.
- **Interactive Developer CLI Sandbox**: In-browser terminal sandbox (`naveen@dev ~ $`) with real-time command parser (`help`, `bio`, `skills`, `projects`, `stats`, `theme`, `sudo hire`).
- **Interactive Particle Glow Canvas**: Real-time cursor-proximity particle grid physics with dynamic radial lighting on the hero section.
- **Synthesized Web Audio Engine**: Zero-asset procedural sound effects generated via Web Audio API oscillators and gain envelopes with global mute/enable toggle.
- **Tiered Architecture Explorer**: Interactive 3-tier inspection matrix (Presentation, Backend API, Cloud Infrastructure) with deep specifications.
- **Multi-Palette Theme Switcher**: 4 tailored dark theme accents (Gold, Cyan, Violet, Emerald) with localStorage persistence.
- **Systematic Performance**: Built on React 19, Vite, Tailwind CSS v4, and Framer Motion with hardware-accelerated animations.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design System Variables
- **Animations**: Framer Motion
- **Audio**: Web Audio API Synthesizer
- **CI/CD**: GitHub Actions & GitHub Pages

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/naveenkumar982/naveenkumar-portfolio.git

# Navigate into project directory
cd naveenkumar-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
